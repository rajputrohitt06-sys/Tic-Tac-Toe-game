# 🎮 Tic-Tac-Toe Game

A simple, responsive, and interactive Tic-Tac-Toe game built using **HTML, CSS, and JavaScript**.

## ✨ Features

- 🎯 Two-player Tic-Tac-Toe gameplay
- ❌ X and ⭕ O player turns
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 📊 Score tracking
- 🔄 New Round functionality
- ♻️ Reset Game functionality
- 📱 Responsive design for desktop and mobile
- ♿ Accessible game controls

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub
